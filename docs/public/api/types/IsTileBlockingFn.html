    Custom function to determine whether a tile is blocking.

    When provided in GridEngineConfigHeadless.isTileBlocking, this function replaces GridEngine's default tile collision logic (including missing-tile checks and ge_collide tile properties).

    Beware that this method is called frequently (especially during pathfinding), so keep it as fast as possible. If your custom collision logic is static or changes infrequently, you can combine it with GridEngineConfigHeadless.cacheTileCollisions.
