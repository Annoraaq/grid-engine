    distance

    distance: number

    Minimum distance to keep from charIdToAvoid in manhattan distance in case of 4 direction mode and Chebyshev distance in case of 8 direction mode.

    When charIdToAvoid is closer than this distance, charId will move along a shortest path to a position with at least this distance.

    OptionalisPositionAllowedFn

    isPositionAllowedFn?: IsPositionAllowedFn

    Function to specify whether a certain position is allowed for pathfinding. If the function returns false, the tile will be considered as blocked.

    It can be used to restrict fleeing to specific regions.

    Beware that this method can become a performance bottleneck easily. So be careful and keep it as efficient as possible. An asymptotic runtime complexity of O(1) is recommended.
